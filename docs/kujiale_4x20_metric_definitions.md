# Kujiale 4×20 通用指标定义与对外表述

> 适用结果：正式 campaign `20260725-210035`。以下先给出可迁移到其他导航项目的通用定义，再说明本实验的
> 测量实现与当前结果。指标公式不包含日志、校验和或具体 ROS 话题名称。

## 1. 通用符号

设某类测试共执行 `N` 轮。第 `i` 轮的实际轨迹长度为 `L_i`，理论最短可行路径长度为 `L_i*`。

- `N_s`：静态障碍测试总轮数；`N_s^succ`：完成规定路线且未碰撞的静态障碍成功轮数；
- `N_d`：动态障碍测试总轮数；`N_d^succ`：完成规定动态交互、规定路线且未碰撞的动态障碍成功轮数；
- `N_goal`：在规定时间内完成全部必经航点的轮数。

“规定路线”“必经航点”“规定时间”和“碰撞”应在测试开始前冻结并对所有轮次一致执行。

## 2. 推荐指标与计算公式

| 指标 | 通用定义与公式 | 当前 `20260725-210035` 结果 | 推荐表述 |
| --- | --- | ---: | --- |
| **静态避障成功率** | 衡量机器人在静态障碍环境中完成任务并安全通过的比例。`ASR_s = N_s^succ / N_s × 100%`。 | `40/40 = 100%` | “静态避障成功率100%。” |
| **动态避障成功率** | 衡量机器人在动态障碍交互中完成任务并安全通过的比例。`ASR_d = N_d^succ / N_d × 100%`。 | `38/40 = 95%` | “三阶段动态避障成功率95%。” |
| **规划相对理论最优路径偏差** | 单轮偏差：`δ_i = (L_i − L_i*) / L_i* × 100%`。批次报告均值 `δ̄ = (1/n) Σ(i=1..n) δ_i` 与最大值 `δ_max = max(δ_i)`。其中 `L_i*` 是在同一任务约束下的理论最短可行路径长度。 | 静态：`δ̄ = 9.3550%`，`δ_max = 10.1687%`，门槛 `≤20%` | “实际路径相对理论最短可行路径的最大偏差为10.17%。” |
| **导航成功率** | 衡量任务完成能力。`NSR = N_goal / N × 100%`。 | 静态 `40/40=100%`；动态 `38/40=95%`；总体 `78/80=97.5%` | “全屋多航点导航成功率97.5%。” |

静态避障成功率与导航成功率在某些项目中可能相同，也可能不同：前者聚焦“通过静态障碍任务”，后者聚焦“完成整条多航点任务”。当前测试的静态障碍贯穿整条规定路线，因此二者同为100%。动态避障成功率则要求完成规定的动态交互，当前为95%。

## 3. 理论最优路径的公平使用方式

`L_i*` 不是忽略机器人尺寸、障碍物或目标姿态的直线距离；它应是使用与实际任务相同地图、障碍约束、机器人
footprint、起终点/航点和可行性约束得到的最短可行路径。因此该指标比较的是“规划与执行效率”，而不是把必要绕障
误判为性能下降。

本项目用冻结地图、六个静态障碍、robot footprint、目标姿态和分辨率生成 `L_i*`；实现上采用
footprint-aware SE(2) 参考规划器。这是**本实验的计算实现**，不是指标定义本身。

动态障碍会随时间改变可行空间，通常不存在对所有轮次公平的固定 `L_i*`。因此当前只对静态场景报告上述路径偏差；
动态场景以动态避障成功率和导航成功率评价，而不与静态参考路径硬比。

## 4. 本实验如何测量

- **任务完成**：以五个必经航点 `G2 → G3 → G4 → G5 → G1` 在规定时间内的导航动作结果判断；
- **碰撞**：以仿真 chassis 接触检测判断；
- **动态交互完成**：以三阶段 actor 状态机完成预定义交互判断；
- **轨迹长度**：由 Ground Truth 位姿序列积分得到；
- **数据可追溯性**：manifest、summary、校验和及逐轮原始证据用于验证数据来源。这是结果审计要求，不是
  避障率或导航成功率公式的额外条件。

低净距和 `safety_yield` 仍在报告中作为风险提示保留；它们不应被表述为“未发生”，也不应在没有实际碰撞时被
直接改写为碰撞失败。

## 5. 对外表述边界

可以使用“在当前酷家乐4×20受控场景下”“静态避障成功率100%”“动态避障成功率95%”“总体导航成功率97.5%”。
不得表述为“所有环境100%成功”“绝不会碰撞”或“动态路径偏差10.17%”（该路径偏差仅在静态固定障碍条件下定义）。

完整4×20报告会自动嵌入相同的实验方法、公式和结果，避免交付材料与原始报告口径漂移。
