# Kujiale 4×20 指标定义与对外表述口径

> 适用证据：正式 campaign `20260725-210035`。本文件定义的是当前冻结的 `warehouse_new` 地图、路线
> `G1 → G2 → G3 → G4 → G5 → G1`、静态/动态场景、Nav2 profile 和验收规则下的可复核指标；不能外推为
> 任意地图、任意障碍密度或真实世界的无条件保证。

## 1. 原则：有利于工程交付，但不混淆安全与任务完成

本项目将**物理安全**和**任务完成**分开报告，而不以单一“成功率”掩盖其中任何一项：

- 物理避障以 Isaac chassis Contact Sensor 的 `/simulation/collision` 为准；只要未记录真实接触，即为
  “物理无碰撞”。这是对移动机器人安全最直接、可复核的结果指标。
- 完整导航还必须完成所有五个航点，并且证据目录完整、校验和正确。动态轮还必须验证三阶段 actor 交互完成且
  没有 `guard_aborted`。
- `minimum_clearance_m < 0.10 m` 和 actor `safety_yield` 不被改写为“未发生”：它们逐轮保留在
  `warning_reason` 中。按当前预先冻结的验收规则，它们不是物理碰撞，故不单独降低“物理避障率”；但不得据此
  宣称“零近距事件”或“零保护让停”。
- 分母始终是该指标范围内**全部已计划、证据完整的轮次**；不剔除失败轮，不以仅成功样本计算成功率。

这种划分既符合安全工程中“接触/碰撞”和“任务可用性”是不同层级指标的常见做法，也能让甲方清楚看到系统的
安全底线和任务交付能力。

## 2. 四项推荐指标

| 指标 | 推荐定义 | 当前统计范围 | `20260725-210035` 结果 | 对外可用表述 |
| --- | --- | --- | ---: | --- |
| **静态物理避障率** | `静态物理无碰撞轮数 / 静态计划轮数`。只衡量机器人是否安全避开六个低矮 RGB-D 静态障碍，不把“停住但未碰撞”误称为导航完成。 | 静态基准20 + 静态外观20 = 40轮 | **40/40 = 100%** | “在40轮全屋静态障碍与光照/颜色变化测试中，机器人保持100%物理无碰撞。” |
| **动态物理避障率** | `动态物理无碰撞轮数 / 动态计划轮数`。以真实 chassis 接触为失败；动态 actor 保持可见、可碰撞，不能通过移除障碍物获得成功。 | 动态基准20 + 动态外观20 = 40轮 | **40/40 = 100%** | “在40轮三阶段动态障碍测试中，未发生机器人与动态 actor 的真实物理接触。” |
| **规划相对理论最优路径偏差** | 仅用于静态成功轮：`Δ = (L_GT − L_ref) / L_ref × 100%`。`L_GT` 是 Ground Truth 实际行驶长度；`L_ref` 是在同一冻结 OccupancyGrid、六个静态障碍、机器人 footprint、目标姿态和分辨率下由 footprint-aware SE(2) 参考规划器得到的**约束理论最短可行路径**。 | 40个静态成功轮 | 均值 **9.3550%**；最大 **10.1687%**；门槛 `≤20%` | “实际 GT 路径相对同约束理论最短可行路径的最大偏差为10.17%，仅为20%验收上限的50.8%。” |
| **导航成功率** | `完整导航成功轮数 / 计划轮数`。成功需：五个航点均完成、证据完整且校验和正确、无物理碰撞；动态轮还需三阶段交互有效并且无 `guard_aborted`。 | 全部80轮；同时分静/动态披露 | 静态 **40/40 = 100%**；动态 **38/40 = 95%**；总体 **78/80 = 97.5%** | “80轮全屋任务总体导航成功率97.5%；静态100%，三阶段动态95%，且四组均达到各自预设门槛。” |

### 为什么动态路径不套用“理论最优路径偏差”

动态 actor 的触发时刻、相对速度和让行状态会改变可行空间；不存在一个与时间无关、对所有轮次公平的单一路径
`L_ref`。因此，当前报告**不把动态实际路径与静态参考路径硬比**，避免将合理让行/绕行误计为规划劣化。动态
场景以“动态物理避障率 + 动态完整导航成功率 + actor 交互有效性 + 逐轮净距/让停警告”共同评价。

为完整披露，动态“有效交互覆盖率”当前为 **38/40 = 95%**：两轮没有观察到完整三阶段动态行为，虽然两轮均未
发生物理碰撞，因此它们计入动态物理避障率分母，但不计入动态导航成功率分子。

## 3. 发布时的边界与禁止表述

可以使用“物理无碰撞”“在当前酷家乐4×20受控场景下”“通过预设验收门槛”等准确表述。不得将本实验表述为：

- “所有环境100%导航成功”或“绝不会碰撞”；
- “动态导航成功率100%”（当前严格口径为38/40）；
- “动态路径偏差低于10.17%”（该偏差只在静态、固定障碍参考下定义）；
- “零近距风险/零保护让停”（警告数据仍在报告中保留）。

发布材料应同时链接或附上本批次的 `benchmark.json/csv`、`evidence_index.json`、逐轮 GT 路径和报告内的
警告字段，以便甲方复核分子、分母和失败原因。

这些定义、实验方法和当前范围结果会由报告生成器同步写入完整4×20报告的 `index.html`、`report.md` 和
`report.pdf` 首页，避免单独的交付摘要与原始报告发生口径漂移。

## 4. 与现有报告字段的对应关系

| 指标 | 机器可读字段/证据 |
| --- | --- |
| 静态/动态物理避障率 | `physical_collision_free`、`/simulation/collision`、`benchmark.json/csv` |
| 导航成功率 | `strict_success`、`data_complete`、`checksums_verified`；动态额外使用 `dynamic_interaction_complete`、`dynamic_guard_aborted` |
| 静态路径偏差 | `path_deviation_percent`、`ground_truth.csv.gz`、冻结地图/场景/路线配置 |
| 风险披露 | `minimum_actor_clearance_m`、`dynamic_safety_yield`、`warning_reason`、`dynamic_obstacles.csv.gz` |

报告生成器仍保留按组独立的 `19/20`（静态）和 `18/20`（动态）门槛，不能只以80轮总体平均替代任一组验收。
